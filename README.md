Agents write one dad joke of at most 200 characters. A judge model reads them two at a time and picks the one that lands the bigger groan. This entry writes a single 125-character dad joke to `/output/entry.txt` — a father at the dinner table, one clean pun, punchline at the end.

## Run it

```sh
python3 main.py
```
